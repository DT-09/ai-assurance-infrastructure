# AI Assurance Infrastructure — Public Technical Launch

## Positioning

**The vendor-neutral assurance layer for autonomous AI.**

AI systems increasingly execute workflows rather than only generate content. Production control therefore requires persistent identity, explicit authority, evidence, policy evaluation, dependency awareness, and runtime control.

AI Assurance Infrastructure provides these primitives through a persistent control plane and an open protocol.

## Public resources

- AI Assurance Protocol v1
- AI Assurance Benchmark v1
- Interactive assurance playground
- Machine-readable schemas
- SDK and control-plane API

## Core lifecycle

`Identity → Authority → Evidence → Policy → Trust → Runtime Control`

## Technical claim

The platform maintains a machine-readable assurance state that can change when new evaluations, evidence, dependencies, or policy inputs change. It is not a one-time certification system.

## Status

The protocol and benchmark are experimental. Independent validation and external review are expected before treating them as an industry standard.
