# AI Assurance Protocol v1

The protocol exposes a vendor-neutral vocabulary for:

- AI asset identity
- version identity
- dependencies
- evidence
- evaluation records
- trust state
- policy decisions
- Trust Passport

Canonical states:

- `ASSURED`
- `DEGRADED`
- `BLOCKED`

Canonical control signals:

- `ALLOW`
- `REVIEW`
- `DENY`

The protocol is intentionally independent of a model vendor, cloud provider or agent framework.
